# CareSlot – Doctor Appointment and Waitlist Management System

CareSlot is a web-based mini project developed using PHP, MySQL, HTML, CSS, and JavaScript. It allows patients to book appointments and helps administrators manage doctors and appointments.

## Live Demo
https://careslot.gt.tc/

## Features
- Patient registration and login
- Admin login
- View, add, and delete doctors
- Book and cancel appointments
- Prevent duplicate bookings for the same doctor, date, and time
- Add patients to a waitlist when a slot is unavailable
- Promote a waiting patient when an appointment is cancelled
- Search appointment records

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Hosting:** InfinityFree
- **Version Control:** GitHub

## Installation
1. Install XAMPP or another PHP and MySQL environment.
2. Place the project folder in the web server directory.
3. Start Apache and MySQL.
4. Import `database.sql` using phpMyAdmin.
5. Configure the database connection in `db.php`.
6. Open the project in your browser using its local URL.

## Database Tables
- `users`
- `doctors`
- `appointments`
- `waitlist`
